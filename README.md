# 推しごと免許証 発行デスク（試作）

## ファイル構成

- `dist/index.html`：受付フォームと免許証プレビューのHTML
- `dist/styles.css`：画面レイアウト、レスポンシブ表示、印刷用のCSS
- `dist/app.js`：参加者管理、写真登録、プレビュー更新、保存・復元の処理
- `server.cjs`：ローカル確認用の静的ファイル配信サーバー

ビルドやライブラリのインストールは不要です。

## GitHub Pagesで公開

公開URL: https://kuwachi626.github.io/oshigoto-license/

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
`.github/workflows/pages.yml` が `main` への更新時に `dist` のみを公開します。ビルド処理は不要で、`server.cjs` は配信しません。

手動で再公開する場合は **Actions → Deploy static site to Pages → Run workflow** から `main` を選んで実行してください。他のブランチでは公開ジョブを実行しません。
実行結果と公開URLはActionsの実行画面で確認できます。公開に失敗した場合は同画面のログとSettings → PagesのSource設定を確認してください。

`index.html` からCSSとJavaScriptを相対パスで読み込むため、`/oshigoto-license/` 配下で動作します。
写真・参加者データは引き続き利用者のブラウザのIndexedDBに保存され、公開ファイルには含まれません。
ローカル版と公開版では保存領域が異なるため、移行時はローカル版でバックアップを保存し、公開版で復元してください。

## 起動と使い方

`dist/index.html` をブラウザで開くか、Node.js がある場合はこのフォルダで `node server.cjs` を実行し http://127.0.0.1:4173 を開いてください。

写真とニックネームを登録 → 保存 → 台紙の資格をチェック → 保存して印刷 → 実際に渡したら「受け渡し済みにする」。最初は「見本を試す」で確認できます。写真なしでは保存できません。

50名まで登録可能。警察と消防は別認定。発行日は参考画像に合わせて2027年3月7日を初期設定としています。カメラ撮影は localhost / HTTPS とカメラ権限が必要です。写真ファイルの選択も利用できます。

写真・参加者データはIndexedDBに保存し、外部へ送信しません。同じブラウザ・同じURLで再開してください。端末間の自動共有はありません。バックアップには写真も含まれます。復元は現在のデータを置き換えます。ブラウザのデータ消去で登録内容が失われるため、必要に応じバックアップしてください。同時に複数タブで編集しないでください。

印刷はA4、倍率100%、ヘッダー・フッターなし。大きめは約148×93mm、カードは約85.6×53.9mmです。背景グラフィックを有効にすると配色が再現されます。必ず実機で試し刷りし、用紙対応とサイズを確認してください。印刷キャンセルと区別するため、受け渡し状況は手動で更新します。

添付のデザインを参考にHTMLで再構成した試作です。元画像のロゴや人物写真は使用していません。本番前にイベント名、職種別の資格名、写真利用の案内、実機印刷を確認してください。
